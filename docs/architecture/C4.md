# C4 views

## Level 1: System context

```mermaid
C4Context
  title Complaint router: system context
  Person(agent, "Complaints handler", "Reviews messages routed to a person")
  System_Ext(intake, "Intake channel", "Web form, email gateway, chat, or fde-00 ingest")
  System(router, "Complaint router", "Predicts the queue; routes to a person when unsure")
  System_Ext(queues, "Case management", "Queues per product or intent")
  Rel(intake, router, "Message text", "HTTPS / JSON")
  Rel(router, queues, "Label + route decision")
  Rel(agent, queues, "Works human-review queue")
```

## Level 2: Containers

```mermaid
C4Container
  title Complaint router: containers
  System_Ext(intake, "Intake channel")
  Container(api, "Router API + UI", "FastAPI, scikit-learn, PyTorch", "Loads model bundles from /app/models at first use")
  ContainerDb(bundles, "Model bundles", "Files baked into the image", "baseline, mlp (+ transformer)")
  Container(train, "Training (build time / CI)", "complaint-router CLI", "Downloads pinned data, trains, evaluates")
  Container(prom, "Prometheus + Grafana", "Monitoring", "Human-review share, confidence, latency")
  Rel(intake, api, "POST /api/v1/predict")
  Rel(api, bundles, "Reads")
  Rel(train, bundles, "Writes during docker build")
  Rel(prom, api, "Scrapes /metrics/")
```
